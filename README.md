# XIAO-MIDI

A firmware for building custom MIDI controllers with the Seeed Studio XIAO RP2350. (for Pico, visit [https://jveski.github.io/pico-midi/](https://jveski.github.io/pico-midi/))

- Supports RP2350 (XIAO RP2350)
- Supports buttons, touch pads, potentiometers, LDR, and accelerometers (LIS3DH, MPU6050, ADXL343)
- Easy installation — download one file and drop it on the board!
- Web interface for configuration

Get started at [https://drc3p0.github.io/XIAO-MIDI](https://drc3p0.github.io/XIAO-MIDI/)
